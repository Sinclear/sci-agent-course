# Научный агент: практикум

Курс для исследователей: как пользоваться агентом так, чтобы результат можно
было защитить. Не «как написать харнес», а «как получить отчёт, где каждое
число имеет источник».

Адаптация курса [justxor/agent-harness-course](https://github.com/justxor/agent-harness-course)
(MIT, © 2026 justxor) под научную работу: литературный обзор, извлечение
методик из статей, проверка цитат, сборка документа по ГОСТ.

## Чему научитесь

1. **Пользоваться pi** как научным инструментом: модели, MCP-источники,
   скиллы, headless-режим.
2. **Понимать, где агент врёт** — прочитать свой мини-харнес (~1000 строк) и
   увидеть места, где теряются факты.
3. **Проверять утверждения** — механизм «цитата или ничего» с метриками и
   eval-набором.
4. **Собирать артефакт** — markdown → docx по ГОСТ с машинной приёмкой (18
   проверок).

## Быстрый старт

```bash
cd ~/projects/sci-agent
make setup         # один раз: .venv с pytest, ruff, mypy
make test          # тесты, без ключей и сети
make lessons       # все уроки 00…06
make evals         # 15 кейсов, precision/recall
make capstone      # обзор литературы из examples/sources

pi --list-models ollama    # что доступно на вашей машине
pi mcp list                # сколько инструментов подключено
```

Всё в `examples/` работает **без ключа и без сети**: там фейковая модель.
Живые прогоны — через `pi` или флаг `--live` в capstone.

## Три правила курса

1. **Цифры из команд, а не из документации.** Версии моделей, число
   инструментов, доступные флаги — брать из `pi --list-models`, `pi mcp list`,
   `pi --help` на своей машине прямо сейчас. Всё написанное здесь устареет.
2. **Цитата или ничего.** Утверждение без дословной цитаты и локатора не
   существует. Ссылка, которую вы не открыли, считается выдуманной.
3. **Измеряйте.** Улучшение без числа (precision, recall, цена, время) —
   самообман. Каждый инцидент с агентом превращается в кейс в `evals/cases.py`.

## Окружение

Python 3.10+. Разработано и проверено на Termux/Android (Python 3.14), работает
на любом Linux. `make setup` создаёт `.venv` и ставит pytest, ruff и mypy —
без этого `make test` падает с «No module named pytest». Дальше `make`
подхватывает `.venv/bin/python` сам. Для модуля 4 нужны `pandoc` и venv с
`python-docx` (см. [docs/04](docs/04-приёмка-гост.md)); на Termux `PIP_USER=0`
при установке в venv, временные файлы — в `$TMPDIR`, а не в `/tmp`.

## Что взято из исходного курса

Взято: архитектура мини-харнеса, идея eval-набора с фейковым HTTP-сервером,
песочница рабочей папки, обрезка истории по порогу без разрыва пар
tool-call/tool-result.

Переработано: все примеры заменены на научные задачи (извлечение методик,
проверка цитат) вместо калькулятора и магазина; убраны фоновые задачи и
субагенты; добавлены журнал провенанса, проверка чисел в цитатах, модуль
приёмки ГОСТ и сравнение с базовой линией «эвристика без модели».
