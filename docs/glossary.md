# Глоссарий

Термины, которые в курсе используются в одном смысле. Если встретили другое
употребление — доверяйте этому списку.

**Агент** — модель плюс цикл: инструменты, история, проверки. Модель без цикла
не агент, а генератор текста.

**Харнес (harness)** — обвязка вокруг модели: как собирается промпт, какие
инструменты доступны, что делается с результатами, когда история обрезается.

**Контекст** — всё, что отправляется модели в одном запросе: системный промпт,
история, результаты инструментов. Имеет предел, который измеряется в токенах.

**Компакция** — замена старой части истории кратким пересказом, чтобы освободить
место. Необратима: подробности исчезают, если их не вынесли в журнал.

**Провенанс** — происхождение утверждения: источник, локатор, дословная цитата.

**Утверждение (claim)** — одно проверяемое предложение с числом или фактом.
Имеет ID, источник, локатор и цитату. Без цитаты не существует.

**Локатор** — место в источнике: страница, таблица, раздел, номер строки.
Считается из файла, а не придумывается моделью.

**Цитата** — дословный фрагмент источника. Проверяется автоматически
(нормализация + совпадение + сверка чисел).

**Порог совпадения** — минимальная похожесть цитаты на текст источника, при
которой утверждение считается подтверждённым. Политика, а не константа.

**Контрольная подмена** — та же цитата с изменёнными числами. Обязана быть
отклонена; если проходит — детектор не работает.

**Precision** — доля верных среди принятых. Для научного текста важнее precision:
принятая выдумка дороже лишней ручной проверки.

**Recall** — доля принятых среди верных. Низкий recall означает, что вы
переписываете руками то, что агент мог сделать сам.

**Eval-набор** — фиксированный список размеченных кейсов с ожидаемым вердиктом.
Память проекта: без него улучшения неотличимы от случайности.

**MCP** — протокол подключения инструментов к агенту. Даёт готовые источники
(arXiv, КиберЛенинка, GitHub, Hugging Face) без написания кода.

**Скилл** — файл с регламентом работы (`SKILL.md`), который агент подгружает по
необходимости. Ваш стиль, ваша структура отчёта, ваши запреты.

**Headless** — неинтерактивный запуск (`pi -p "..."`). Всё, что требует
подтверждения, блокируется: делите чтение и запись.

**ГОСТ-приёмка** — машинная проверка docx (`verify.py`): поля, интервалы,
стили, подписи. 18 проверок, код возврата 0 — единственный критерий «оформлено».

**Токен** — единица текста для модели. Для русского научного текста ≈ 2–3
символа, а не 4: оценка «длина ÷ 4» занижает расход в 1.5–2 раза.
