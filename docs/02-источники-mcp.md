# 02. Источники: как искать литературу, чтобы ссылки были настоящими

Модуль на 1.5 часа. Цель — ссылка, которую можно открыть, а не строка,
похожая на ссылку.

## Где брать

Четыре источника, у каждого своя ниша. Все — только чтение, поэтому проходят
гейт подтверждений молча.

| Источник | Что ищет | Ограничение |
|---|---|---|
| arXiv | препринты, свежее; 19 инструментов: поиск, аннотация, полный текст, граф цитирований | почти нет русскоязычных, много нерецензированного |
| КиберЛенинка | русскоязычные статьи с полным текстом (20–24 тыс. знаков) | нет DOI-валидации, качество журналов разное |
| GitHub | код и данные к статье | это не публикация, ссылаться надо на статью |
| Hugging Face | датасеты, модели, их карточки | только для воспроизводимости, не для теории |

## Порядок работы

1. **Сформулируйте вопрос как поисковый запрос на английском** для arXiv и на
   русском для КиберЛенинки. Один и тот же смысл, два языка — разные корпуса.
2. **Сохраните идентификатор, а не ссылку.** `arXiv:2405.12345` переживёт
   переезд сайта; URL — нет.
3. **Прочитайте аннотацию и выводы, не полный текст.** Полный текст — только
   для тех 5–7 работ, которые действительно нужны.
4. **Выпишите цитату сразу, с локатором.** Позже вы не найдёте, где это было.
5. **Проверьте, существует ли статья в рецензируемом виде.** Препринт и статья
   в журнале — разные источники с разной силой утверждения.

## Практика

```bash
# поиск по arXiv с полным текстом
pi -p "найди 5 работ по теме 'KV cache compression' за 2024-2026,
       для каждой дай arXiv ID, год и одну фразу о вкладе"

# русскоязычный корпус
pi -p "найди в КиберЛенинке 3 статьи про квантизацию LLM,
       дай ссылку и цитату с выводом (не пересказ)"
```

Проверка результата: возьмите первую ссылку и откройте её. Если открылась
другая работа или 404 — весь список отправляется в мусор, и это нормальный
исход первого прогона.

## Антипаттерны

- **«Дай 10 источников по теме»** — получите 10 правдоподобных названий без
  статей. Просите по одному, с проверкой.
- **Пересказ вместо цитаты.** «Авторы показали, что квантизация ухудшает
  качество» — непроверяемо. Нужна фраза из текста.
- **Ссылка на обзор вместо первоисточника.** Обзор удобен, но утверждение из
  него — это утверждение обзора.
- **Дата без места.** «В 2024 году вышла работа» — какая, где, ID?

## Как это выглядит в коде

`sci_harness/tools.py` — минимальный набор для локальных файлов
(`list_dir`, `read_file`, `write_file`, `edit_file`, `pdf_extract`,
`table_extract`). Удалённые источники в курс не
вшиты намеренно: их подключение — это MCP, то есть урок модуля 1, а не код
харнеса.

В `examples/02_agent_loop.py` агент получает папку с текстом статьи и должен
выписать утверждения. Посмотрите, что он делает, если файла нет: честный
агент скажет «файл не найден», нечестный — придумает содержание.

## Чек-лист модуля

- [ ] знаю ID хотя бы одной работы в своей области наизусть
- [ ] умею получать цитату с локатором, а не пересказ
- [ ] проверяю ссылки перед тем, как вставить в текст
- [ ] отличаю препринт от рецензируемой публикации

## Открытый вопрос

КиберЛенинка и arXiv дают текст, но не дают надёжных метаданных для
библиографии (ГОСТ-оформление). Список литературы придётся нормализовать
руками или своим скриптом — это тема модуля 5.
